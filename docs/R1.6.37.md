# MediaDock R1.6.37

## Clip Range + Queue Batch Controls

- Shows detected media duration in a dedicated Clip Range column, separate from Title / Video Source.
- Supports start/end download ranges using mm:ss or hh:mm:ss and applies the selected section to both MP4 and MP3 output.
- Adds queue-wide format choices: Keep each item's format, All as MP4, or All as MP3.
- Adds a persisted parallel-download setting from 1 through 5, with a hard maximum of 5.
- Removes ETA from download progress/status while retaining percent, downloaded size, speed, and state.
- Preserves existing queue controls, original-audio/dub selection, output-folder behavior, strict trial accounting, licensing, and customer state.
