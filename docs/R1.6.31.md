# MediaDock R1.6.31 - Queue Icon Actions and Safe Delete

- Compact six-icon Queue actions: Download, Subtitles, Copy Source Link, Convert to MP3, Download as MP4, Delete.
- Tooltips replace action text to preserve row width.
- Delete operations offer Yes = delete downloaded files + queue rows, No = queue rows only, Cancel = do nothing.
- Failed file deletions keep their queue rows.
- Download Ready is disabled when Queue is empty or a download/conversion task is active.
- Includes cumulative R1.6.30 full-license consistency, 5-concurrent queue, Output Folder, and original-audio work.
