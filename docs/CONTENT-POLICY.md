# Content access boundary

Media Downloader is built for lawful personal, church, archival, educational, and creator workflows.

It can work with public media and media that the user is legitimately authorized to access. Authentication support, when added, will use the user's own browser/session credentials locally.

The application does not include DRM decryption or DRM-circumvention functionality. If an underlying service reports that the only available media is DRM-protected, the job should stop with a clear diagnostic rather than attempting to bypass the protection.

Users remain responsible for copyright, platform terms, permissions, and applicable law for the media they download.
