# MediaDock R1.6.39

## Queue UX and Audio / Dub

- Protects Format, Quality, Audio / Dub, Clip Range, Progress, Status, and Actions from long-title layout pressure.
- Long titles stay in the title column, wrap to two lines, and retain the complete title in a tooltip.
- Queue action buttons use a consistent rounded compact style.
- Adds a visible per-row Audio / Dub selector that reuses MediaDock's existing yt-dlp FormatId path.

## Safe Delete

- Remove from MediaDock removes only the queue entry and keeps downloaded files on the computer.
- Delete from Computer is the only destructive choice and deletes only the selected row's downloaded output file.
- Cancel, Escape, and closing the dialog change nothing.

## Audio Formats

- Adds M4A and FLAC download outputs alongside MP3.
- MP3, M4A, and FLAC share the existing strict audio trial allowance; changing formats cannot bypass trial accounting.
- Selected Audio / Dub and Clip Range are honored by the existing queue download path.

## Clipboard Detection

- Adds an optional Detect copied media links setting under Downloads.
- It is disabled by default.
- When enabled, a supported copied media URL can be analyzed after explicit user confirmation.
- Clipboard detection never starts a download automatically.

## Validation

- Windows Release build must pass before repository publication.
- Engine contract tests and startup smoke test must pass.
- Public repository publication uses an explicit allowlist, staged-diff secret scan, remote-head recheck, and no force-push.
