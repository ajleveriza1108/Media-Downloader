## Trial and licensing

- Video: 5 successful outputs;
- MP3: 5 successful outputs.

Buy MediaDock License and the centered Enter Serial action remain available before trial exhaustion.

Admin and customer licenses activate the same installed MediaDock application; no separate full-version executable is required. The private client validates against the owner-hosted licensing backend and supports Release This Device.

Updates do not reset trial/license state.

## Installer updater

The app reads only:

https://raw.githubusercontent.com/ajleveriza1108/MediaDock-Release/main/latest-stable.json

Contract version: schema 3 / installer-only.

The updater rejects development metadata, inactive stable pointers, same/older versions, non-MediaDock release URLs, non-EXE artifacts, malformed SHA-256 values, and unpublished installers.
